# Capturas del proyecto

Esta carpeta guarda las imágenes que el README principal muestra. Se esperan
dos archivos con estos nombres exactos:

| Archivo | Qué debe mostrar | Ancho de ventana |
|---|---|---|
| `listado.png` | La rejilla de países con el buscador y el filtro visibles. | 1440 px |
| `detalle.png` | La ficha completa de un país, por ejemplo El Salvador. | 1440 px |

Opcionalmente, para documentar el comportamiento adaptable:

| Archivo | Qué debe mostrar | Ancho de ventana |
|---|---|---|
| `movil.png` | El listado en una columna, con el botón de menú. | 390 px |
| `menu-movil.png` | El menú desplegado sobre el listado. | 390 px |

Cómo tomarlas en Chrome: `F12` → `Ctrl+Shift+M` → escribe el ancho exacto en
el campo *Dimensions* → menú `⋮` del panel de dispositivo → **Capture
screenshot**. Para la página completa, `Ctrl+Shift+P` → «Capture full size
screenshot».
